## 📌 About the Project

CODE WITH MATT is a personal portfolio website developed to present my information, educational background, technical skills, and projects in one place.

This project also serves as an application of my knowledge in front-end web development.

## ✨ Features

- Personal introduction and profile section
- About Me section
- Technical skills showcase
- Project gallery with screenshots
- Education and achievements section
- Contact information
- Light and dark theme switcher
- Responsive website layout
- Mobile navigation menu

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive layout
- JavaScript — Interactive functionality
